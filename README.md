# 借书之问 · 个人阅读系统

以一本书为线索，追问自己的生活。11个主题，83个已有阅读单元。公开入口：https://byteleee.github.io/QTB/

## 现在怎样阅读

1. 从书架开始，或在“调整本周安排”选择一本主读、可选轻读和每周分钟预算。
2. 点击“预览安排”再采用。默认40分钟；仍可选择原来的按期数模式。本周读不完可以先放下，不增加欠账。
3. 读完一期只留下一个自己的回答，也可以暂时不写。已读表示读过，不代表掌握。一周后可回看旧回答。
4. 回首页继续阅读；正文按段落恢复，改稿后段落不存在会提示并近似恢复。重读保留以前的完成和回答。
5. 听读可记住声音与语速，支持续听、跳段、定时停止。设备是否提供中文声音、锁屏与后台能否继续播放，应以实际浏览器为准。
6. 备份支持文件和文本合并导入，保留冲突历史与目录外的笔记，导入前有恢复点；撤回时还保留恢复前记录，并可导出该版本。手机可显示完整备份文本后复制。记录仅在当前浏览器，跨设备手动备份，不上传公开仓库。

## 当前内容源

`content/themes/*.json`是当前版唯一正文与元数据编辑源。每期有永久`id`、展示次序、独立问题、正文、版本说明；三篇样板另有逐项核查的`evidence`。`content/editorial-review.json`记录全部83期的论证路线、反例和资料范围，与正文ID严格对齐。不要按新排序重建id。旧`book`/`episode`链接兼容，新入口使用永久id。

构建：

```text
python3 scripts/build-reading-system.py
node --test tests/*.test.cjs
python3 scripts/validate-reading-content.py
python3 site/downloads/agent-control-experiment.py
python3 site/downloads/agent-reading-labs.py --all
```

构建生成reading-data、11个guide.html思想地图、逐期current-XX.html打印页与纯文本正文稿。current、guide和txt是构建产物，不手工修改。旧书籍目录、内容JS与各书旧构建脚本保留为存档，不再是当前版编辑入口。旧页标注存档，私人编辑请使用统一阅读器。

GitHub Pages工作流对main提交自动构建、校验和发布site。无需额外后端。

## 质量与验收

先完成系统之美1、土星之环1和Agent2三篇样板；随后将34篇拼接稿按论证顺序合编，补齐Agent其余11期独立开场和全12期基础实验，改写土星之环六处通用软件类比，修复日本史资料编号和崩盘八期共用回答提示。全部83期有逐期论证与边界记录。

这些是可回查的具体编修，不等于83篇原著全文逐句核读。原有连贯稿件按实际需要保留，未为了凑数量全部重写。
